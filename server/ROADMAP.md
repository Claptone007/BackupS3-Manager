# BackupS3 Manager Server 25.0 — план реализации

## Этап 1 — работающий каркас (готов)

- ASP.NET Core Server для Debian 13;
- вход администратора через защищённую cookie;
- постоянное атомарное JSON-хранилище;
- совместимые `/agent/enroll` и `/agent/heartbeat`;
- Dashboard агентов и баз из их отчётов;
- self-contained `linux-x64` пакет и установка как systemd-служба.

## Этап 2 — управление

- создание, редактирование и назначение баз агентам;
- очередь команд проверки и загрузки;
- профили S3 и проверка соединения;
- S3-проводник, политика хранения и журнал операций;
- импорт конфигурации из Windows Manager 24.x.

## Этап 3 — эксплуатация

- HTTPS через Caddy с локальным сертификатом или доменом;
- роли администратора и оператора;
- PostgreSQL как дополнительное хранилище для крупной установки;
- уведомления, метрики за 30 дней и резервное копирование состояния;
- обновление с проверкой SHA-256 и автоматическим откатом;
- готовый Proxmox helper-script создания Debian 13 LXC.
