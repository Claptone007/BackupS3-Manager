# BackupS3 Manager

Windows-приложение для контроля локальных резервных копий, загрузки в S3, проверки синхронизации и автоматической очистки старых объектов.

## Версия

Текущая стабильная версия: **23.14**.

## Возможности

- управление базами и несколькими S3-профилями;
- ручная и автоматическая проверка резервных копий;
- загрузка и политика хранения файлов в S3;
- безопасный режим, журнал действий и диагностика;
- фоновая работа в системном трее;
- сохранённая или новая конфигурация при запуске;
- обновления через GitHub Releases с проверкой SHA-256.

## Сборка

Требуются Windows, PowerShell 7, .NET 8 SDK и WiX Toolset 4.

```powershell
.\Test-Project.ps1
.\Build-MSI.ps1
```

Результаты создаются в `dist/app` и `dist/msi`.

В репозитории используется пустая безопасная конфигурация. Реальные имена баз, пути, S3-бакеты и ключи AWS сюда не публикуются.
